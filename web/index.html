How to read this record

Cutoff and time. Classification is fixed when a report is accepted. “Accepted at” is server time sampled before acceptance finishes; it does not establish the exact save time or event order.

Evidence and completeness. The ledger is authoritative for accepted reports. MeterProof does not verify whether the source reported all usage.

Live view and preserved results. Live values can reflect different reads. Pending means usage outside the latest snapshot shown above. Preserved snapshots stay unchanged. Automatic projection alerts and cloud recovery are not implemented.

Operator responsibility. An operator triggers close and adjustment. The demo does not enforce roles or approvals. Usage adjustments do not create or change invoices or payments.
